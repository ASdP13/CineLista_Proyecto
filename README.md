# Contenido de la rama

* Requisitos de la practica 3 para la creación de la página "Estadísticas"
  1. Estadisticas contiene un DataTable usando REST
  2. Un filtro de buscador
  3. Un footer con el total de taquilla de las peliculas del DataTable
  4. Notas mostradas con un gráfico
  5. Un botón para exportar DataTable como CSV con nombre de archivo personalizado
