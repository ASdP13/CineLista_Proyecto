# CineLista Practica 3 - Desarrollo de interfaces

Autores: Alexander Selivanov y Álex Segura

# Contenido de la rama

Codigo completo del proyecto CineLista cumpliendo con:
* Requisitos de la practica 3 para la creación de la página "Estadísticas"
  * Estadisticas contiene un DataTable usando REST
  * Un filtro de buscador
  * Un footer con el total de taquilla de las peliculas del DataTable
  * Notas mostradas con un gráfico
  * Un botón para exportar DataTable como CSV con nombre de archivo personalizado
